tsgonest ships two npm packages that you interact with directly:

| Package | Purpose |
| --- | --- |
| [`@tsgonest/runtime`](/docs/api/runtime) | Config helper, error types, decorators, and interceptors |
| [`@tsgonest/types`](/docs/api/types) | Zero-runtime branded types for type-safe validation constraints |

The main `tsgonest` package is the CLI binary — see the [CLI Reference](/docs/cli) for its documentation.
